Four stages, from backlight to veil

Windows offers one slider, and only on screens that accept it. An image actually passes through four stages before reaching the eye, and each one is adjustable — that is what makes 5 % to 150 % possible.

  1. Backlight

    The real light of the panel, through WMI on a laptop or DDC/CI on an external monitor. When it answers, it is the best stage: less light emitted, not merely less light shown.

    All or nothing, depending on the screen

  2. Gamma ramp

    The graphics card's colour table, rewritten channel by channel. This is where temperature, contrast, curve and balance live — and the only stage that can multiply, hence go past 100 %.

    From 35 % to 150 %

  3. Colour matrix

    Saturation and filters, including colour-blindness correction. Windows exposes it for the whole desktop only: the software therefore names the reference screen explicitly, rather than picking one at random.

    Whole desktop

  4. Veil

    A semi-transparent black window that receives no clicks. Below 35 % it takes over, where the gamma ramp would start crushing the blacks. It is also what this page is doing right now.

    From 5 % to 35 %

Two colours you cannot tell apart, pushed apart until you can

On the left, two colours as a colour-blind person sees them today. On the right, the same two after correction, seen by that same vision. The colours are not chosen for effect: they are built along the confusion axis, with the software's own matrices, and the distance is measured in Delta E exactly as the software measures it.

70 %

Below 2.3 Delta E the eye no longer separates two colours; above it, it does. The correction invents no colour: it moves the difference onto the channels still perceived. The simulation remains a published approximation — a starting point that the test then refines.

The colour vision test, in two minutes

Picking “deuteranopia, severity 100 %” from a list means filing yourself under a label. A correction calibrated for a complete deficiency makes the screen garish for someone who only has part of one — and that is most people concerned.

  1. Plates find the type

    A digit hidden in a field of dots. The colours are searched by calculation among hundreds of candidates, and kept only if the digit vanishes for the targeted deficiency while staying obvious for the other two. Two control plates, readable by everyone, catch random answers.

  2. Measurement finds the severity

    The gap narrows after every correct answer and widens after every mistake, until it converges on your own limit. This is the staircase method used for threshold measurement in psychophysics. When the plates hesitate between two neighbouring axes, all three are measured and the profile of the measurements decides.

  3. The result applies, and is saved

    Under whatever name you choose, and it touches colours only: recalling “charts” will never change your brightness. If nothing stands out clearly, the test says so rather than inventing an answer.

This is a calibration tool, not a medical test. It tunes software from what you see on this particular screen, whose brightness and colour profile affect the result. Telling a mild protanomaly from a mild deuteranomaly requires an anomaloscope, and the software says so whenever that doubt exists. For a diagnosis, see an eye specialist.

What is guaranteed, and by which test

Questions

Is it really free?

Yes, and free as in freedom: AGPL v3. No paid tier, no reserved feature, no trial period.

Windows shows a warning on first launch.

The file is not signed by a commercial certificate, which costs a few hundred euros a year. SmartScreen says “Windows protected your PC”: choose More info, then Run anyway. The repository also builds with a single command, if you would rather not trust a binary.

How is this different from f.lux or Night light?

Colour temperature is the common ground. Beyond that: brightness runs from 5 % to 150 %, each screen is adjusted separately, and the colour-blindness side — adjustable correction plus a measurement test — is not offered free elsewhere.

Does it work on an external monitor?

Yes. Brightness, temperature and veil are set per screen. Saturation and colour filters apply to the whole desktop: that is a limit of the Windows interface, and the software names the reference screen rather than hiding it.

Does the test replace an eye examination?

No, and it says so. It calibrates software from what you see on this screen; a diagnosis requires a clinical examination. If the test finds something unexpected, talk to a professional rather than to software.

Where are the settings stored?

In %LOCALAPPDATA%\OpusScreen\settings.ini. A text file, backed up by copying, exportable from the Advanced tab.

Which Windows versions?

Windows 7 to 11. The software relies on .NET Framework 4, present on all of them: nothing to install.

Is the interface available in English?

Not yet — the interface is French. The concepts are visual (sliders, plates, colour pairs), but the labels are not. If you need an English interface, open an issue: that is how it gets prioritised.
